# Fairhaul Carton Sizing fixtures

Fictional products, cartons and charges.

- `cartons.json`: a five-carton catalog (S1 to L1), the 139 divisor, 1 inch of padding and an average 1.10 per billable lb.
- `packages.csv`: nine parcels. Lamp shades go out in M2 when M1 fits (22 billable lb instead of 12); one candle set goes in M1 when S2 fits; a rug ships in a 50-inch custom carton that triggers an oversize charge, though a 48-inch carton would take it; a mirror needs a carton the catalog does not have.

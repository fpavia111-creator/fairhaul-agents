# Fairhaul LTL Reweighs fixtures

Fictional carriers, products and amounts, October 2026.

- `corrections.csv`: eight LTL weight and class corrections. A bookcase kit is corrected three times, heavier and to a higher class each time, with certificates: the shipper's own item data is wrong. A floor lamp is reweighed 10 lb heavier (within scale tolerance). Patio chairs are reclassed from 85 to 125 although their density supports 85, and a second load of them is reweighed 20 lb heavier with no certificate. A rug bundle has no certificate. A mirror crate is reclassed with no dimensions on file, so it cannot be checked.
- `terms.json`: the defaults written out.

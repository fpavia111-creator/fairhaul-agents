# Regulus fixtures

Fictional carriers, contracts and shipments, October 2026.

- `contracts.json`: three LTL contracts in the Lodestar contract format (per-hundredweight lanes with minimums, fuel tables, accessorial prices) and a weekly diesel index.
- `history.csv`: seven shipments with what was paid. Three Chicago to Texas loads went to Ridgeline Freight, which is not the cheapest contract on that lane; three Chicago to Atlanta loads were split; one Atlanta delivery needs residential, which one contract does not price; one Ohio load has no contract lane anywhere.

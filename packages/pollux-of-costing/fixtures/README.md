# Pollux fixtures

Fictional items and three months of freight by SKU (August to October 2026).

- `items.csv`: seven items with standard freight per unit and units on hand.
- `actual-freight.csv`: freight by shipment and SKU. The October rows match Castor's allocation of the same shipments.
  - FLOOR-RUG and LAMP-SHADE cost far more than standard, and rising, so the proposal uses October.
  - BOOKENDS cost less than standard.
  - DOOR-MAT ships but has no standard. MIRROR has too few units to judge. PLANTER did not ship.
